1. A Analogia da Caixa
Imagine que você recebe uma caixa de presente.

No Java antigo, você tentava abrir a caixa sem olhar. Se estivesse vazia, você "explodia" (NullPointerException).

Com o Optional, o Java te entrega a caixa fechada. Você tem ferramentas para perguntar: "Tem algo aí dentro?" ou "Se não tiver nada, me dê esse outro presente no lugar".

2. O Código: Do Erro à Solução
Para a sua captura de tela, mostre este contraste. É o que faz o aluno entender o valor da ferramenta.

O Problema (Onde tudo quebra):






// 1. Criamos a "caixa" que pode ou não ter um nome
Optional<String> caixaNome = Optional.ofNullable(nome);

// 2. Em vez de arriscar, definimos uma alternativa:
String resultado = caixaNome.orElse("Nome não informado");

System.out.println(resultado); // Imprime: Nome não informado (Sem erros!)



3. Os 3 Comandos que "Salvam Vidas" no Backend
Mostre esses três métodos, pois são os que ele mais usará com bancos de dados:

orElse(): "Se não tiver nada, use este valor padrão". (Ex: Nome de usuário anônimo).

ifPresent(): "Se tiver algo, execute essa ação". (Ex: Mandar um e-mail apenas se o endereço existir).

orElseThrow(): "Se não tiver nada, lance um erro específico". (Muito usado em APIs para dizer: "Usuário não encontrado").


----------------------------------------
List<String> usuarios = Arrays.asList("Ana", "Beto", "Carlos");

// Queremos achar o primeiro usuário que começa com "Z"
String usuarioEncontrado = usuarios.stream()
    .filter(n -> n.startsWith("Z"))
    .findFirst() // Isso retorna um Optional!
    .orElse("Nenhum usuário com Z encontrado");

System.out.println(usuarioEncontrado);
